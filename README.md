# Projeto Nuxt - Cadastro de Membros

Aplicação web desenvolvida utilizando Node.js, Vue.js e Nuxt.js.

## Tecnologias utilizadas

* Node.js
* Vue.js
* Nuxt.js
* TypeScript
* HTML
* CSS

## Funcionalidades

* Página inicial
* Navegação entre páginas
* Página de cadastro
* Validação de formulário
* Seleção de interesses
* Limite de caracteres na bio
* Feedback visual após o cadastro
* Exibição dos dados no console

## Como executar

Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

Entre na pasta:

```bash
cd atividade-nuxt
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```

Acesse no navegador:

```text
http://localhost:3000
```

## Rotas

* `/` - Página inicial
* `/cadastro` - Formulário de cadastro
